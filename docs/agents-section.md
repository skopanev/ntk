**Все задачи ведутся через `ntk`. Ничего другого, никакого Notion API.**

Инструменты подключены по MCP и сами описывают, что принимают. Начните с
`ntk_whoami`, если не знаете, какой воркспейс называть: он обязателен везде и
по умолчанию не подставляется.

```
ntk_whoami   кто я и какие воркспейсы доступны
ntk_ls       список; по умолчанию свои, all=true — все
ntk_show     тикет целиком
ntk_next     взять следующий свободный; prefer — порядок тегов, не фильтр
ntk_start    взять конкретный
ntk_close    закрыть
ntk_create   завести
ntk_update   изменить: статус, заголовок, тело, исполнителя и теги ОДНИМ вызовом
ntk_tag      только теги
ntk_deps     на чём стоит и что стоит на нём
ntk_rm       убрать
ntk_meta     статусы, приоритеты, проекты, люди
ntk_modules  модули проекта; архивный виден, но выбрать его нельзя
```

Правила, которые не видны из описаний инструментов:

- **Тикет вне группы `todo` уже кем-то подобран** — правка требует `force`.
  Ставьте осознанно, вы вмешиваетесь в чужую работу.
- **Меняйте одним вызовом.** `ntk_update` принимает статус, тело и теги сразу и
  применяет их одной транзакцией. Несколько вызовов оставляют тикет видимым
  наполовину изменённым.
- **Теги идут со знаком**: `+добавить`, `-убрать`. Без знака отвергается, иначе
  «добавить» однажды окажется «заменить всё».
- **Перед закрытием опишите, что сделано** — в теле через `ntk_update`. Без
  этого закрытие бессмысленно: следующий не поймёт, чем всё кончилось.
- **Заводите тикет только когда об этом просят.** Починка бага, ревью, ответ на
  вопрос — не повод.
- **Очередь сама поднимает блокеры начатого.** Тикет, который держит уже
  начатую работу, срочен настолько, насколько срочно то, что он держит, —
  `ntk_next` учитывает это сам, по всей цепочке. Собирать такой выбор вручную
  из `ntk_ls` и `ntk_deps` не надо: между чтением и взятием есть окно, а
  захват в `ntk_next` атомарен.
- **Модуль тикета берётся из списка проекта.** `ntk_modules` показывает и
  архивные: на архивный модуль тикет не заводится и не переназначается, а те,
  что уже на нём стоят, правятся как обычно.
- **Ссылайтесь на код по имени** функции или уникальному фрагменту, не по
  номеру строки: номера устаревают.
